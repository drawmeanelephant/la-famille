## Midnight

This page demonstrates the `layout-midnight` layout: a restrained dark theme
for technical writing, with monospaced metadata, flat surfaces, and hairline
borders.

No glassmorphism, no glow. Just a calm reading surface that stays legible at
2am.

### Built for docs and devlogs
- Monospaced kicker and footer for a terminal feel
- Sectioned prose with quiet rules between headings
- Fully offline: system fonts, no frameworks, no CDNs

func main() {
    fmt.Println("ships in the dark, runs anywhere")
}
